# CASH-FLOW-DASHBOARD
Cash Flow Dashboard – Power BI Project  Interactive cash flow dashboard built in Microsoft Power BI to analyze income, expenses, profit trends, and financial performance. This dashboard provides clear visual insights into cash inflows and outflows, helping businesses track financial health and make data-driven decisions.

Features :
Dynamic cash flow analysis
Income vs expense tracking
Monthly and yearly financial trends
KPI cards for profit, revenue, and balance
Interactive filters and slicers
User-friendly and responsive dashboard design

Tools & Technologies :
Power BI Desktop
Data Visualization
DAX Functions
Power Query
Financial Data Analysis

Dashboard Insights :
Monitor business cash flow performance
Identify spending patterns
Compare revenue and expenses over time
Support strategic financial planning
